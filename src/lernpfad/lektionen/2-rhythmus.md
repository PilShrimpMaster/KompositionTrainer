## Erklären

Die Form einer Note sagt, wie lange sie klingt. Jeder Notenwert ist halb so lang wie der vorige:

| Note | Länge in Vierteln |
| --- | --- |
| Ganze Note | 4 |
| Halbe Note | 2 |
| Viertelnote | 1 |
| Achtelnote | ½ |
| Sechzehntelnote | ¼ |

Ein **Punkt** hinter der Note verlängert sie um die Hälfte ihres Werts: Eine punktierte Halbe dauert 3 Viertel, eine punktierte Viertel 1½. Ein **Haltebogen** verbindet zwei gleiche Töne zu einem langen. So kann ein Ton über den Taktstrich klingen. Für jede Note gibt es eine **Pause** mit derselben Länge.

Die **Taktart** am Anfang sagt, wie viele Schläge in einen Takt passen. 4/4 heißt vier Viertel, 3/4 drei Viertel (Walzer, Menuett), 6/8 sechs Achtel in zwei Gruppen. Die erste Zählzeit eines Takts ist betont.

```noten
titel: Dreivierteltakt mit punktierter Halben
takt: 3/4
tonart: 1

G4:4 A4 B4 | D5:2. | C5:4 B4 A4 | G4:2.
```

## Hören

Zähl beim Anhören mit: „eins, zwei, drei“. Wo fällt die Betonung hin? Danach dasselbe im 6/8-Takt, gezählt „eins zwei drei, vier fünf sechs“ mit zwei schweren Schlägen pro Takt.

```noten
titel: Sechsachteltakt
takt: 6/8
tempo: 72

C5:8 D5 E5 F5:4 E5:8 | D5:4. G4 | E5:8 F5 G5 A5:4 F5:8 | E5:4. C5
```

```noten
titel: Haltebogen über den Taktstrich

E4:4 G4 C5:2~ | C5:4 B4 A4 G4 | F4:2. E4:4 | C4:1
```

## Freie Aufgabe

Denk an ein Lied, das du gut kennst, und klopfe seinen Rhythmus. In welcher Taktart steht es? Schreib die ersten zwei Takte nur mit einer Tonhöhe (z. B. immer c″), sodass nur der Rhythmus zählt. Spiel es ab und vergleiche mit deiner Erinnerung.

## Quiz

? Wie viele Viertel dauert eine punktierte Halbe?
+ 3
- 2½
- 4
- 2
= Der Punkt verlängert um die Hälfte: 2 + 1 = 3 Viertel.

? Wie viele Achtel passen in eine punktierte Viertel?
+ 3
- 2
- 4
- 1½
= Eine punktierte Viertel dauert 1½ Viertel, also drei Achtel.

? Was bewirkt ein Haltebogen zwischen zwei gleichen Tönen?
+ Sie klingen als ein langer Ton zusammen
- Der zweite Ton wird lauter gespielt
- Die Töne werden gebunden, aber neu angeschlagen
- Der zweite Ton wird zur Pause

? Wie zählt man einen 6/8-Takt?
+ Sechs Achtel in zwei Gruppen zu je drei, mit zwei schweren Schlägen
- Drei Gruppen zu je zwei Achteln
- Sechs gleich betonte Achtel
- Wie einen 3/4-Takt, nur doppelt so schnell
= Darum wirkt 6/8 wiegend: „eins zwei drei, vier fünf sechs“.

? Welche Taktart haben Walzer und Menuett?
+ 3/4
- 4/4
- 6/8
- 2/4

? Welche Zählzeit ist in jedem Takt betont?
+ Die erste
- Die letzte
- Die zweite
- Keine, alle sind gleich

? In einem 4/4-Takt stehen schon eine Halbe und eine Viertel. Was fehlt noch?
+ Eine Viertel
- Eine Halbe
- Eine Achtel
- Nichts, der Takt ist voll
