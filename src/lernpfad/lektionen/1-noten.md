## Erklären

Noten stehen auf fünf Linien, dem Notensystem. Je höher eine Note steht, desto höher klingt sie. Jede Linie und jeder Zwischenraum ist ein Stammton: C, D, E, F, G, A, H. Danach beginnt die Reihe in der nächsten Oktave wieder mit C.

Welcher Ton auf welcher Linie liegt, bestimmt der Schlüssel am Anfang:

- Der **Violinschlüssel** umkreist die zweite Linie von unten. Dort liegt das g′. Er wird für hohe Stimmen benutzt: Melodie, rechte Hand am Klavier, Sopran, Saxophon.
- Der **Bassschlüssel** setzt seine zwei Punkte um die vierte Linie. Dort liegt das f. Er wird für tiefe Stimmen benutzt: linke Hand, Bass, Cello.

```noten
titel: Stammtöne im Violinschlüssel

C4:4 D4 E4 F4 G4 A4 B4 C5:4
```

Das mittlere c′ liegt genau zwischen beiden Systemen: im Violinschlüssel auf einer Hilfslinie unten, im Bassschlüssel auf einer Hilfslinie oben.

```noten
titel: Stammtöne im Bassschlüssel
schluessel: bass

C3:4 D3 E3 F3 G3 A3 B3 C4:4
```

Die deutschen Namen der Oktaven helfen beim Sprechen über Töne: großes C, kleines c, eingestrichenes c′ (das mittlere C), zweigestrichenes c″. Ein **Kreuz** erhöht einen Ton um einen Halbton (F wird Fis), ein **b** erniedrigt ihn (E wird Es). Achtung: Im Deutschen heißt der Stammton zwischen A und C **H**, und das erniedrigte H heißt **B**.

## Hören

Hör dir die Beispiele oben noch einmal an und sing leise mit. Achte darauf, dass jeder Schritt im Notensystem ein Schritt nach oben in der Tonhöhe ist, egal ob von Linie zu Zwischenraum oder umgekehrt.

```akkorde
klang: nacheinander
C4 | C#4 | D4 | Eb4 | E4
```

Hier hörst du dieselbe Strecke in Halbtönen: C, Cis, D, Es, E. Zwischen E und F sowie zwischen H und C gibt es keine schwarze Taste, dort liegt der Halbton schon zwischen zwei Stammtönen.

## Üben

Lies Noten in beiden Schlüsseln, bis du jede Note ohne Abzählen erkennst. Die Aufgaben werden schwerer, sobald du sicherer wirst: zuerst Stammtöne, dann Hilfslinien und Vorzeichen.

```uebungen
noten-lesen
```

## Schreiben

```aufgabe
titel: Stammtöne von c′ bis c″
text: Schreibe die acht Stammtöne von c′ aufwärts bis c″ im Violinschlüssel. Benutze ganze oder halbe Noten und keine Vorzeichen.
tonart: 0
takt: 4/4
schluessel: treble
pruefung: tonleiter
```

## Freie Aufgabe

Stell im Editor den Bassschlüssel ein und schreibe eine kurze Melodie, die zwischen dem großen G und dem c′ bleibt. Lies dir danach jede Note laut mit ihrem deutschen Namen vor, mit Oktavlage (z. B. „kleines e“). Schalte die Notennamen im Editor zur Kontrolle ein.
