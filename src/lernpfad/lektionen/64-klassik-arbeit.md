## Erklären

Die wichtigste Technik der Wiener Klassik ist die **motivisch-thematische Arbeit**: Aus einem kleinen Motiv wächst ein ganzer Satz. Haydn hat sie entwickelt, Beethoven auf die Spitze getrieben. Der Anfang von Beethovens 5. Sinfonie besteht aus vier Tönen (drei kurze, ein langer), und fast der ganze erste Satz ist aus ihnen gebaut.

Die Werkzeuge, mit denen ein Motiv verändert wird:

| Technik | Was passiert |
| --- | --- |
| **Wiederholung** | Das Motiv erklingt noch einmal, oft auf anderer Stufe (Sequenz). |
| **Abspaltung** | Nur ein Teil des Motivs wird weiterverwendet, meist der Schluss. |
| **Liquidation** | Das Motiv wird Schritt für Schritt abgebaut, bis nur Rhythmus, Tonleiter oder Akkord übrig bleiben. Danach ist Platz für die Kadenz. |
| **Umkehrung** | Die Richtung der Intervalle wird gespiegelt. |
| **Vergrößerung / Verkleinerung** | Doppelte oder halbe Notenwerte. |
| **Intervallveränderung** | Der Rhythmus bleibt, die Intervalle werden größer oder kleiner (aus der Terz wird eine Sexte). |
| **Rhythmische Variante** | Die Töne bleiben, der Rhythmus ändert sich (punktiert, synkopiert). |
| **Kombination** | Zwei Motive erklingen gleichzeitig oder werden aneinandergehängt. |

**Abspaltung und Liquidation** findest du besonders im **Satz** (Stufe 4): Die Präsentation stellt den Grundgedanken zweimal vor, die Fortspinnung spaltet einen Teil ab, verkürzt ihn immer weiter und mündet in die Kadenz. Je kürzer die Glieder, desto stärker der Drang nach vorn.

**Die Mannheimer Schule.** Am Hof in Mannheim spielte um 1750 das beste Orchester Europas. Seine Effekte wurden zum Allgemeingut der Klassik:

- **Mannheimer Rakete**: ein schnell aufsteigender gebrochener Dreiklang über mehrere Oktaven.
- **Mannheimer Walze**: ein langes Crescendo über einem gleichbleibenden Bass, vom Pianissimo zum Fortissimo.
- **Mannheimer Seufzer**: fallende Sekunden auf leichter Zeit, sehr ausdrucksvoll.
- **Generalpause**: Alle verstummen plötzlich.

Neu ist die **dynamische Gestaltung durch Übergänge**: Crescendo und Decrescendo statt Terrassen wie im Barock, dazu harte Akzente (*sforzato*, **sf**), die Beethoven besonders liebte.

## Vertiefen

**Ein Motiv durch eine Durchführung führen.** Eine typische Durchführung arbeitet so:

1. **Modulation** gleich zu Beginn in eine entferntere Tonart.
2. Das Kopfmotiv wird **sequenziert**, oft mit Imitation zwischen Bass und Oberstimme.
3. **Abspaltung**: Nur noch der Motivkopf, immer dichter hintereinander.
4. **Liquidation** bis auf einen einzigen Akkord oder Ton, häufig über einem **Orgelpunkt auf der Dominante**.
5. Die Spannung entlädt sich in der **Reprise**.

**Monothematik bei Haydn.** Haydn bildet in vielen Sonatensätzen auch das Seitenthema aus dem Hauptthema, nur in der Dominante und anders begleitet. So hängt alles aus einem Keim zusammen.

**Entwickelnde Variation.** Schönberg nannte Brahms’ Weiterführung dieser Technik „entwickelnde Variation“: Jede neue Gestalt geht aus einer Veränderung der vorigen hervor, nichts wird bloß wiederholt. Diese Denkweise ist auch heute die Grundlage, wenn du aus einem Motiv einen ganzen Song, Filmcue oder Track entwickelst.

## Hören

Das Kopfmotiv von Beethovens 5. Sinfonie und seine Sequenz eine Stufe tiefer.

```noten
titel: Beethoven: Kopfmotiv der 5. Sinfonie
tonart: -3 moll
takt: 2/4
tempo: 108
r:8 G4:8 G4:8 G4:8 | Eb4:2 | r:8 F4:8 F4:8 F4:8 | D4:2
```

Ein **Satz** mit Abspaltung und Liquidation: Takt 1–4 präsentieren den Grundgedanken zweimal, Takt 5–6 spalten nur dessen Schlussfigur (drei Töne abwärts) ab und sequenzieren sie aufwärts, Takt 7 löst alles in eine Tonleiter auf, Takt 8 kadenziert. Zeig die Form an.

```noten
titel: Übung: Satz mit Abspaltung und Liquidation
tonart: 0
tempo: 100
form: ja
C5:4 E5:8 D5:8 C5:4 G4:4 | A4:4 F4:4 G4:2 | D5:4 F5:8 E5:8 D5:4 A4:4 | B4:4 G4:4 A4:2 | E5:8 D5:8 C5:4 F5:8 E5:8 D5:4 | G5:8 F5:8 E5:4 A5:8 G5:8 F5:4 | E5:4 D5:4 C5:4 B4:4 | C5:1
```

Eine **Mannheimer Rakete**: ein Dreiklang, der in einem Atemzug nach oben schießt.

## Schreiben

```aufgabe
titel: Ein Satz mit Abspaltung
text: Schreib einen achttaktigen Satz in F-Dur. Takt 1–2: ein Grundgedanke mit klarem Motiv. Takt 3–4: derselbe Gedanke eine Stufe höher (über der Dominante). Takt 5–6: Verkürze das Motiv auf halbe Notenwerte und setze es mehrmals direkt hintereinander, jedes Mal eine Stufe höher (Sequenz). Takt 7–8: Liquidation zu einer Tonleiter und Ganzschluss auf f.
tonart: -1
pruefung: takte 8, satzform, ganzschluss-takt 8, stilmerkmal sequenz
```

```aufgabe
titel: Das Kopfmotiv verarbeiten
text: Erfinde ein Kopfmotiv aus vier Achteln in C-Dur (zum Beispiel c – d – e – c) und verarbeite es über acht Takte. Setze es mindestens zweimal direkt hintereinander auf einer anderen Stufe (Sequenz), bring es außerdem in doppelten Notenwerten (Vergrößerung) oder gespiegelt (Umkehrung). Der letzte Ton ist c.
tonart: 0
pruefung: takte 8, stilmerkmal sequenz 2, endet-grundton
```

## Freie Aufgabe

Hör den ersten Satz von Beethovens 5. Sinfonie mit der Partitur (zum Beispiel auf IMSLP) und zähl, in wie vielen Takten der ersten Seite das Kopfmotiv steckt, auch versteckt in Begleitstimmen. Nimm dann dein eigenes Kopfmotiv aus der Aufgabe und schreib eine kleine Durchführung von acht Takten: Beginne in a-Moll, sequenziere den Motivkopf, spalte ab und ende auf einem langen G als Dominante zu C-Dur.

## Quiz

? Was bedeutet motivisch-thematische Arbeit?
+ Ein ganzer Satz wird aus einem kleinen Motiv entwickelt
- Jedes Thema bekommt ein neues Motiv
- Die Melodie wird über einem festen Bass variiert
- Das Thema wird nur wörtlich wiederholt

? Was ist Abspaltung?
+ Nur ein Teil des Motivs wird weiterverwendet
- Das Motiv wird rückwärts gespielt
- Das Motiv wird in doppelten Notenwerten gespielt
- Zwei Stimmen tauschen das Motiv

? Was geschieht bei der Liquidation?
+ Das Motiv wird abgebaut, bis nur Rhythmus, Tonleiter oder Akkord bleiben
- Das Motiv wird verdoppelt
- Ein neues Thema ersetzt das Motiv
- Das Motiv wird eine Oktave höher wiederholt

? Was bleibt bei einer Intervallveränderung gleich?
+ Der Rhythmus
- Die Intervalle
- Die Tonart
- Die Lautstärke

? Was ist eine Mannheimer Rakete?
+ Ein schnell aufsteigender gebrochener Dreiklang über mehrere Oktaven
- Ein langes Crescendo über gleichem Bass
- Eine fallende Sekunde auf leichter Zeit
- Eine plötzliche Pause aller Instrumente

? Was ist die Mannheimer Walze?
+ Ein langes Crescendo über einem gleichbleibenden Bass
- Ein Walzer im 3/4-Takt
- Eine schnelle Tonleiter
- Ein Akkord, der rollend gebrochen wird

? Was steht in der Durchführung oft direkt vor der Reprise?
+ Ein Orgelpunkt auf der Dominante
- Ein Trugschluss
- Eine Fuge
- Ein neues Seitenthema

? Was ist typisch für Haydns Monothematik?
+ Auch das Seitenthema wird aus dem Hauptthema gebildet
- Ein Satz hat gar kein Thema
- Jeder Satz hat drei verschiedene Themen
- Das Thema erklingt nur einmal

? Wie nannte Schönberg die Technik von Brahms, bei der jede Gestalt aus der vorigen hervorgeht?
+ Entwickelnde Variation
- Zwölftontechnik
- Fortspinnung
- Thematische Transformation

? Was bedeutet sf (sforzato)?
+ Ein plötzlicher, harter Akzent
- Sehr leise
- Allmählich lauter
- Mit Dämpfer
