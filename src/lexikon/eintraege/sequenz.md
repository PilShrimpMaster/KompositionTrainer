In einer **Sequenz** wird ein Baustein mehrmals auf anderen Tonstufen wiederholt, z. B. das Motiv C–D–E, dann D–E–F, dann E–F–G.

- **Tonale Sequenz**: Die Wiederholungen bleiben in der Tonart, die Intervalle ändern sich dabei leicht (groß/klein).
- **Reale Sequenz**: Die Intervalle bleiben exakt gleich, dabei entstehen leiterfremde Töne; die Musik kann so modulieren.

Spöttisch nennt man eine allzu mechanische, stufenweise steigende Sequenz eine **Rosalie** (nach einem Gassenhauer). Sequenzen sind ein wichtiges Mittel, Melodien weiterzuspinnen, besonders im Barock.
