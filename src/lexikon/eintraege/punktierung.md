---
id: punktierung
titel: Punktierung
kategorie: Rhythmus
kurz: Ein Punkt hinter der Note verlängert sie um die Hälfte ihres Werts: Eine punktierte Halbe dauert drei Viertel.
synonyme: Punkt, punktiert, punktierter Rhythmus
siehe: notenwert, haltebogen
---

Der **Punkt** hinter einer Note (oder Pause) fügt die Hälfte ihres eigenen Werts hinzu:

- punktierte Halbe = Halbe + Viertel = **3 Viertel**
- punktierte Viertel = Viertel + Achtel = **1½ Viertel**
- punktierte Achtel = Achtel + Sechzehntel

Ein **zweiter Punkt** fügt noch einmal die Hälfte des ersten Punkts hinzu: Eine doppelt punktierte Viertel dauert 1¾ Viertel.

Typisch ist der **punktierte Rhythmus** „lang – kurz“ (punktierte Viertel + Achtel), etwa am Anfang von „Ode an die Freude“ im vierten Takt oder in Marschmusik.
