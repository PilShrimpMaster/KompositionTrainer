titel: Transponierende Instrumente
kategorie: Instrumente
kurz: Instrumente, die anders klingen als notiert: Das Altsaxophon in Es klingt eine große Sexte tiefer, Klarinette und Trompete in B eine große Sekunde tiefer.
synonyme: transponierendes Instrument, in B, in Es, in F, B-Stimmung, Es-Stimmung, klingend notiert
siehe: transposition, saxophon, holzblaeser, blechblaeser
---

Viele Blasinstrumente gibt es in verschiedenen Größen. Damit Spieler zwischen ihnen wechseln können, ohne neue Griffe zu lernen, wird so notiert, dass dieselbe Note immer denselben Griff hat. Der klingende Ton hängt dann von der Größe ab.

| Instrument | Stimmung | notiertes c″ klingt als |
| --- | --- | --- |
| Sopransaxophon, Klarinette, Trompete | B | b′ (große Sekunde tiefer) |
| Altsaxophon | Es | es′ (große Sexte tiefer) |
| Tenorsaxophon | B | b (große None tiefer) |
| Baritonsaxophon | Es | es (Oktave plus große Sexte tiefer) |
| Horn | F | f′ (Quinte tiefer) |

Der Name sagt, welcher Ton erklingt, wenn ein C notiert ist: Beim Altsaxophon in Es klingt das notierte C als Es.

Eine Partitur kann **klingend** notiert sein (alle Stimmen wie sie erklingen) oder **transponiert** (jede Stimme so, wie der Spieler sie liest).
