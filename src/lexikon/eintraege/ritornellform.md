Der Ablauf eines typischen schnellen Satzes bei **Vivaldi** oder **Bach**:

| Abschnitt | Besetzung | Tonart |
| --- | --- | --- |
| Ritornell | Tutti | Tonika |
| Episode | Solo | moduliert |
| Ritornell, verkürzt | Tutti | Dominante oder Parallele |
| Episode | Solo | moduliert weiter |
| Ritornell, verkürzt | Tutti | weitere verwandte Tonart |
| Episode | Solo | zurück |
| Ritornell | Tutti | Tonika |

Das Ritornell ist meist eine **Fortspinnung**: ein prägnanter Kopf, eine sequenzierende Mitte, ein kadenzierender Schluss. Die mittleren Ritornelle bringen oft nur einen Teil davon. Auch das **Rondo** der Klassik lebt vom Wechsel zwischen einem wiederkehrenden Refrain und Zwischenteilen.
