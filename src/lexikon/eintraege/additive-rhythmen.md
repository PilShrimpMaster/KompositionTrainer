Im **additiven** Rhythmus wird der Takt nicht in gleiche Teile geteilt, sondern aus Gruppen zusammengesetzt:

| Takt | Gruppen |
| --- | --- |
| 5/8 | 2 + 3 oder 3 + 2 |
| 7/8 | 2 + 2 + 3 |
| 8/8 | 3 + 3 + 2 |
| 9/8 | 2 + 2 + 2 + 3 |

**Bartók** übernimmt diese **bulgarischen Rhythmen** aus der Volksmusik des Balkans. **Strawinsky** lässt im *Sacre du printemps* die Taktart fast in jedem Takt wechseln.

**Messiaen** entwickelt zwei eigene Techniken:

- **Valeur ajoutée**: An einen regelmäßigen Rhythmus wird ein kleiner Wert angehängt, als Note, Punkt oder Pause. Das Metrum gerät ins Schweben.
- **Nicht umkehrbare Rhythmen**: Rhythmen, die vorwärts und rückwärts gleich sind, wie ein Palindrom (kurz – lang – kurz).

Die Gruppierung 3 + 3 + 2 ist heute der Grundrhythmus unzähliger Pop-, Reggaeton- und Latin-Tracks.
